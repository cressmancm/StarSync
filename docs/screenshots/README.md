# Screenshots

Captured on a Retina display with `screencapture -o -l <window>`, which takes
the window alone at its natural size and leaves out the drop shadow — smaller
files, and the web page gets to place its own shadow. Every file here is
1640 × 1184, the app's 820 × 592 window at 2×.

All of them are the **StarSync Demo** album. Those fourteen photos are cleared
for the public repo and for chipcressman.com/starsync; no other album's are, so
anything shot against the whole catalog stays out of this folder.

Smart albums are not listed in the chooser, deliberately — their membership is
a stored predicate with no `album_asset` rows, so there is nothing to read.
Don't expect one in a shot.

## Not illustrated

The **Matched more than one photo** section has no shot, and can't easily get
one. It only lists photos that are rated in Lightroom *and* matched more than
one photo in Photos, and none of the fourteen in StarSync Demo are both. The
only place it appears is a whole-catalog run, whose thumbnails are not cleared
for publishing. Putting one in would mean adding an ambiguous photo to the demo
album and rating it.

## Before publishing

These show real photographs from Chip's library as thumbnails. The repo is
public and the shots also go on chipcressman.com/starsync, so that's a
deliberate decision rather than something to assume.

## Keeping them honest

Retake the set when the UI changes enough that a shot misrepresents it. A
screenshot of a version that no longer exists is worse than none.
